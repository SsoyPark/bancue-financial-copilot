# BANCUE 5분 데모

## 데모 목표

은행 상담 문의가 들어왔을 때 BANCUE가 개인정보를 가리고, 위험도와 의도를
분류하고, 검증된 공식 근거만 연결해 답변 초안을 제공하는 흐름을 보여준다. 검색에
실패하거나 위험도가 높을 때 자동 처리를 멈추는 안전장치와 상담사 피드백을 통한
품질 개선 과정까지 설명한다.

## 실행 준비

터미널 1에서 API를 실행한다.

```bat
cd apps\api
python -m uvicorn app.main:app --reload --port 8000
```

터미널 2에서 웹을 실행한다.

```bat
cd apps\web
npm run dev
```

웹 주소는 `http://localhost:5173`이다. 데모 전에 `python -m pytest -q`가 모두
통과하는지 확인한다.

## 시연 순서

### 1. 상담 목록 — 30초

- 위험도와 대기시간으로 처리 순서를 구분한다.
- 고객 정보가 마스킹된 상태로 표시된다는 점을 설명한다.

설명 문장:

> 상담사가 모든 문의를 처음부터 읽는 대신 위험도와 처리 상태를 기준으로 우선순위를 확인합니다.

### 2. 일반 상담 검토 — 2분

- `21-1_bk_03_000002_001` 예금 만기 상담을 연다.
- AI 분석에서 의도, 위험도, 판정 이유와 필수 확인 항목을 확인한다.
- `검색 판단 상세`을 열어 후보 점수와 8점 기준을 보여준다.
- `답변 검토`에서 근거 문서를 펼쳐 공식 출처와 답변 초안을 확인한다.

설명 문장:

> 답변을 바로 생성하지 않고 최소 검색 점수를 통과한 검증 문서가 있을 때만 초안을 만듭니다.

### 3. 고위험 안전장치 — 1분

- `21-1_bk_03_000005_001` 해외송금 상담을 연다.
- 위험도가 `Critical`임을 확인한다.
- 승인 대신 관리자 이관만 가능하다는 점을 보여준다.

설명 문장:

> 고위험 상담은 근거와 초안이 있어도 자동 승인할 수 없도록 사람 검토를 강제했습니다.

### 4. 검색 중단 설명 — 45초

- `지식 관리`의 검색 판단 확인에 아래 질문을 입력한다.

```text
해외송금 회사에 취업하려면 어떤 자격증이 필요한가요?
```

- 최고 후보가 8점 미만이므로 검색을 중단하는 결과를 확인한다.

설명 문장:

> 금융 용어가 포함됐다는 이유만으로 무관한 문서를 연결하지 않도록 최소 점수 게이트를 적용했습니다.

### 5. 상담사 피드백과 품질 관리 — 45초

- 상담 상세의 `품질 피드백` 탭을 연다.
- 의도 파악 5점, 답변 초안 4점을 저장한다.
- 3점 이하에서는 개선 사유가 필수로 나타나는 것도 설명한다.
- `품질 관리`에서 평균점수와 최근 기록을 확인한다.

설명 문장:

> 정답셋 평가뿐 아니라 실제 상담사 피드백을 항목별 점수로 수집해 다음 개선 대상을 구분합니다.

## 데모 완료 체크리스트

- 상담 목록과 상세 화면이 정상적으로 열린다.
- 개인정보 마스킹, 위험도 이유와 규칙 ID가 표시된다.
- 공식 근거 URL과 검색 판단 점수가 표시된다.
- 일반 상담에는 근거 기반 초안이 생성된다.
- 고위험 상담은 승인이 제한된다.
- 범위 밖 질문은 검색을 중단한다.
- 1~5점 피드백이 저장되고 품질 관리에 집계된다.

## 표현할 때 주의할 점

- `전체 금융 상담 정확도 100%`라고 설명하지 않는다.
- `공식 공개자료 요약 5개와 정답셋 15개에서 전체 정확도 1.00`이라고 범위를 밝힌다.
- 검색 점수는 정답 확률이 아니라 키워드 규칙 점수라고 설명한다.
- 현재 답변 초안은 외부 LLM이 아닌 근거 기반 템플릿이라고 설명한다.
